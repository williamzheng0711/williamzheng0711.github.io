# Generated JourneySphere deployment

Do not edit map code or geometry here. Maintain them in the JourneySphere project and rerun its scripts/export-static.mjs through the consuming website's sync command.

export-manifest.json records the source base commit, exact source hashes (including local changes), input record hash and deployed file hashes. The base commit alone does not identify uncommitted source changes.

Country URLs are deployment configuration generated from the chosen fallback data URL. Keep that URL pinned to a compatible atlas release. Software and geographic-data attribution are in LICENSE and data/README.md.
